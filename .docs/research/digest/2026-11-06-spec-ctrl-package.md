## 1. The three arms (decode-control2 §3, each independently gated, ALL default OFF)

**STRATA_SPEC_LOGISTIC — tables become logistic priors, ω online-fit.** `SurvivalEstimator` (include/strata/spec/controller.hpp, src/spec/controller.cpp): per-position `p = σ(ω·logit(q_max) + β_k)`, one shared slope, K_MAX intercepts — the vLLM shipped form. β seeds from the house tables (`logit(0.86)`), is seeded ONCE from the engine's own depth EMAs at the first folded window (re-seeding per window would clobber every refit), then the IRLS fit owns it. Labels fold at the dp-update site (generate.cpp) with the identical censoring rule (positions ≤ accepted+1); refit every 100 windows, ridge 1e-3, damping n/(n+50) on the slope and n_k/(n_k+50) per intercept — the digest's §3.4 law verbatim. Sizing composes WITH W1, not beside it: inside the existing `STRATA_ADAPTIVE_SPEC` block, after `ctrl.set_mtp_accept(p, K_MAX)` from the dp EMAs, the armed path overwrites the controller's table with `ŝ_k = σ(ω·f_k + β_k)` where `f_k = logit(dprob[k])` is THIS window's own drafted confidence — the current window's logits modulate the prior exactly as §3.3 rule 2 says. The W1 math (`expected`, `choose`, `step_ms`, `min_gain`, the warm gate, the cut-only clamp) is untouched. Feature validity: greedy argmax drafts give `dprob = q_max` exactly (prefix-only, lossless-safe); coupled-sampled windows have no prefix-only feature on the host and keep the bare prior (f = 0). Two guards the refit needed on this rig's data shape (found by dry-run, fixed, re-probed): the ridge is NOT damped (a damped ridge zeroed the diagonal of evidence-free positions and silently killed the whole refit), and the Newton step is multiplied by the same evidence factors with ω clamped to [0.05, 4.0] — a narrow-feature session (deep positions only ever see low-confidence drafts) is near-collinear, and ungoverned IRLS walks that valley to ω=−3/β=+11 nonsense; ω→0 degrades safely to the bare tables, ω ≤ 0 inverts confidence. Realistic-spread probe: ω converges 0.975 on truth 1.0, β's within 0.25 of truth at 40 refits.

**STRATA_SPEC_ENTABORT — host-side decay-knee abort of the serial draft chain.** The drafter's per-step trim loops in `MtpDrafter::draft()` gain one predicate beside the existing min_p gate: stop after position i when `σ(ω·logit(q_i) + β_i) < s_min` (s_min = 0.10, the §3.3 survival floor) OR `1 − γ·H_i < λ` (γ = 0.2, AdaEDL). q_i is the per-step prob the trim already reads (`h_prob_`, mapped); H_i is new: when armed BEFORE the first capture, `record_rest` captures one `row_typical_stats` node per step (the EXISTING one-block kernel, `draft = −1` so only out[1] = entropy is used — zero new kernel code, zero new D2H: the node writes straight into 2·kVerifyMaxT floats of mapped staging, `h_stat_`). Three insertion points in draft(): the gated loop's launch condition (the abort SAVES the step launches — `STRATA_DRAFT_UNGATED` unset is the default shape), the ungated readout trim, and the min_p≤0 path (readout-only — the stale-signal pre-launch shape §3.3 rule 3 prescribes under graphs: this window's rows are already paid, the NEXT window sizes from the shorter chain). λ runs AdaEDL's tuning law at the fold site: EMA α=0.9 of realized acceptance, clamped [0.3, 0.9]. Parameters ride on the drafter per round via `set_draft_abort(DraftAbort)` — plain members, nothing captured; slot drafters (batch lane) never receive it, so their graphs stay byte-identical even armed. The abort is serial-lane only (`mtp.draft`); the pipeline lane (`chain_launch`) is untouched — W2's phase-coupling note stands. Telemetry: `strata spec-ctrl:` line per request (ω, refits, folds, windows, chains cut via the new `MtpDrafter::n_aborts`, λ).

**STRATA_SPEC_SURVTOPK — global survival top-K row allocation at conc.** The batch lane's two window-packing sites (the cohort `collect` lambda and the inline single-window walk in `batch_step`) branch to `survtopk_pack` when armed: candidates are the (slot, depth-prefix) rows, ranked by the survival product over the slot's OWN `dprob` (already host-resident, BSlot), admitted greedily under the untouched 8-row cap. D-cut's invariants hold by construction: per-slot survival is monotone non-increasing in depth, so the global sort admits contiguous prefixes whole (KV reads stay per-slot contiguous); the base/bonus row rides with its slot's first admitted draft (every admitted slot keeps ≥ its bonus token); each slot's rows are base token + drafts [0, depth) at pos p, p+1, ... — identical row semantics to today's packing. Draftless slots rank last (-1, rotation order preserved by stable_sort) and take a row only when rows remain — today's overflow deferral. The W1 cost model sets no new budget: the cap is the budget, survival only allocates it — at solo it is a no-op, at ≤4-slot shapes where everything fits it admits exactly today's window, and the gain mechanism is the §3.5 one: ~1–1.5 rows/window move from ~0.1-survival tails to ~0.85-survival prefixes at identical row count. Rotation advance is preserved per lane (`next_slot` / cohort `next_cur` from the last admitted slot).

## 2. The observe() fix (the rig-specific hazard, in scope)

The extrapolation block is deleted from `Controller::observe` (src/spec/controller.cpp): the four lines that pulled every unobserved deep position toward the deepest observed rate. The replacement per the design is the damped IRLS refit — `SurvivalEstimator::refit()` — which is what the LOGISTIC arm feeds W1 with. The unit test now pins the corrected law both ways: one all-accepted window at k leaves every untested position at its prior, and the estimator test shows growth coming from per-position evidence under damping instead.

**The unswitched case (requirement 1's escape hatch, argued):** `Controller::observe` has ZERO call sites in the engine — grep over src/ + include/ finds `Controller` only at generate.cpp:16293 (`set_mtp_accept` + `choose`; a fresh instance per window, state living in the dp arrays) and in `controller_test.cpp`. The extrapolation law never executes in the standing binary. With the switches off, the decode-path textual deltas are: loop bound literals 8 → `kVerifyMaxT` (same value), a short-circuited `!abort_after(...)` that returns false on the first check when disarmed, and an `abort_at` initialized to max_steps whose trim condition never fires; the GPU graphs capture without the stats node, so the device side is byte-identical. Verdict: pure bug fix on a test-only path; decode behavior provably unchanged. The engine-side growth risk the digest names lives in the dp_ok/dp_tested lifetime counting (never extrapolating) and is now additionally bounded by the estimator's damped refit when armed.

## 6. Boundaries (named, with owners)

- **Coupled-sampled windows fold no feature** (f = 0, prior-only): the sampled token's probability is not a prefix function; the losslessness argument forbids it. Cost: the estimator's slope learns from greedy windows only. Owner: revisit if `row_typical_stats` gains a max-softmax output (out[2] = q_max) — then coupled windows fold the same feature.
- **Entropy at inv_t = 1**: the draft head's raw-logit softmax; coupled sampling's temperature scale is not applied. The abort targets the greedy/argmax serial lanes; a coupled-depth lane would want the scaled softmax.
- **Serial lane only** for LOGISTIC/ENTABORT (where W1 lives); the pipeline lane (`chain_launch`) and slot drafters are untouched — the §3.3 phase-coupling note (pre-launch sizing under graphs) is the design's own law, not a gap.
- **IRLS guards** (undamped ridge, damped step, ω ∈ [0.05, 4.0]) are dry-run-derived on this rig's degenerate feature shape; the 4000-window realistic probe converges (ω 0.975 on truth 1.0). If L1's AUC passes but ω sits at a clamp boundary, widen the band, not the falsifier.
- **SURVTOPK draftless-slot ranking** (base candidates last) is the row-count-parity choice; the alternative (bases first) collapses the window to bonus-only rows at 8 active slots and was rejected — the reasoning lives in the pack's helper comment.
