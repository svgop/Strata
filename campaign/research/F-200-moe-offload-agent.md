# Research brief 2: MoE offload + planning (agent, 2026-10-15) — 12 findings

Ranked findings for our shape (2% CPU-routed tail, batch 1-6, 48 layers, 31 ms window, 4.90 ms all-or-nothing host round trip):

1. **llama.cpp persistent expert slot pool** (github.com/ggml-org/llama.cpp/discussions/28248) — expert-id→slot-id indirection through a host-maintained I32 map applied with plain get_rows (zero new kernels); LRU update + async H2D miss copies + table rewrite in the split prologue = graph-replay-safe ordering. Measured +84% decode at N=64 slots on RTX 4090 all-CPU. Break-even: caching pays when hit ≥ 1 − PCIe_BW/RAM_BW. VERDICT: adopt — the closest known implementation of our T1.1 partial plan.
2. **vLLM incremental MoE offloading RFC** (vllm-project/vllm#38256) — score=freq/age GPU cache + persistent int32 expert_map with −1 for non-resident (NOT remapped topk ids — quant-scale mismatch trap on FP8, relevant to IQ3_S blocks). Prefetch net-negative at bs=1; dedup topk before load; static profile-driven placement beats positional +73-130%. VERDICT: adopt the expert_map contract + no-prefetch-at-bs=1.
3. **KTransformers expert deferral** (LMSYS blog 2025-10-22, SOSP'25 paper, kvcache-ai/ktransformers) — CPU tail experts executed ONE LAYER LATE, overlapped with next-layer GPU attention (residuals tolerate it): +1.45× decode, <0.5% accuracy change; async task scheduling keeps CUDA graphs intact. VERDICT: adopt — cheapest structural fix; pin tail workers to the V-cache CCD.
4. **Speculating Experts** (arXiv:2603.19289) — next-layer routing predicted via quasi-hidden-state (LN of post-attn residual + per-expert default activation) through the EXISTING router, no training; mispredictions executed anyway; ~90% next-layer recall on Qwen3-30B-A3B; 5-14% TPOT cut. VERDICT: phase 2 after 1-3.
5. **Pre-attention expert prediction** (arXiv:2511.10676, ETH) — 1-2 linear layers cloned to CPU predict the CURRENT layer's experts from pre-attn activations, hidden inside the attention window (~0.15 ms); 93-97% exact top-k; over-provisioning k+2..k+4 → 98.6-99% hit. VERDICT: adopt; simplest highest-recall predictor.
6. **HOBBIT** (arXiv:2411.01433) — misses ranked by gating magnitude ‖G(x)‖ (0.99 Pearson with output contribution): important misses full precision, unimportant 2-bit stub or SKIPPED above T₂; top-1 always full. Stacked gating = ~96% next-layer top-1 prefetch. VERDICT: adopt T₂-skip + gating ranking; 2-bit tail-copy tier optional (17.7 GB → ¼ size duplicates).
7. **LLRU** (arXiv:2509.02408) — layer-aware eviction: evict largest R(p,t)=⌊(t−τ)/ℓ⌋, tie-break D(p,t)=(τ−t) mod ℓ; ~15% fewer faults than LRU; NEVER shard the cache per layer-group (unbounded-bad). VERDICT: adopt — ~5-line change to our age-based policy.
8. **VERIFIED CONSTRAINT: SM120** (vllm#43507, #35566, vllm discuss 2536) — SM120 has 99 KiB shared (vs 228 on SM100); TMA-WS grouped GEMM illegal/fails; the supported RTX 5090 MoE path is Marlin-class LUT-dequant kernels (vLLM PR #24722) or FlashInfer SM12x fused MoE. TRT-LLM dense-GEMM MoE loses at ≤32 tokens AND needs tcgen05. VERDICT: any grouped-GEMM rewrite must be Marlin-style; port TRT's aux-stream router+topk+alpha overlap pattern only.
9. (TRT-LLM scheduling pattern — folded into 8.)
10. **ik_llama.cpp / illama** (github.com/ikawrakow/ik_llama.cpp, codeberg illama) — AVX-512 GEMV/GEMM for 2-3-bit IQ quants + fused MoE ops, ~2-3× CPU-side on Zen 4/5. VERDICT: mine kernels for the CPU tail (matters only after 1-5 remove the round trip).
11. **Zen5 reality check** — decode GEMV is dual-channel-DDR5-bound (~95 GB/s); our 2% tail is tens of MB/layer-group = sub-ms compute → the 4.90 ms is OVERHEAD-dominated, confirming avoidance/overlap >> CPU kernel work. Keep ~1 core free per CCD.
12. **FluxMoE** (arXiv:2604.02715) — CUDA VMM page-rebind for graph-safe hot-swap; BUT 0.64× at small batch. VERDICT: steal VMM rebind only if H2D miss copies show in profiles.

**Takeaway:** 1-3 attack the 4.90 ms round trip structurally (slot indirection + graph-safe maps + cross-layer deferral), each independently deployable; 4-6 make layer-groups miss-free (90-99% coverage + importance-gated tail); SM120 MoE kernels must be Marlin-class.
