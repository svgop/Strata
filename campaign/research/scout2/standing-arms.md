# SCOUT-2 — standing-arms mimic/adherence gate (2026-10-26)
Every mature shop gates kernel changes with: fixed-prompt replay vs a STORED BASELINE artifact, distribution-level stats, per-sample drill-down. None gate on small-N aggregate accuracy alone.
- **SGLang PR #10230 (A-, most adoptable):** ~1000-prompt baseline pickle (pinned release, on HF); CI samples a few hundred, compares top-logprobs. RETURN_ORIGINAL_LOGPROB=True neutralizes sampler variance. Threshold = max/mean SPLIT: dense max<=1.5 mean<=0.1; MoE max<=10 mean<=0.3. Issue #19164: cross-arm stochastic compare = distribution-level metrics (channel mean/var drift), same-code reproducibility = bit-exact; author CI budget <=15 min; drift localization by per-layer snapshot.
- **llama.cpp --kl-divergence (A, best gate math):** baseline logits once, then PPL ratio, mean KLD, same-top-p rate, and the DECISIVE test: **delta-p percentiles — symmetric tails = pure noise; negative tails = genuine degradation**. Calibration floors: bf16-vs-fp16 KLD 2.5e-5, same-top-p 99.74%. "Identical PPL 8.3729" = same-binary determinism, not cross-build (FP16 reruns vary ±0.038).
- **vLLM perf-eval (B+):** diff-vs-baseline on a fixed recipe + error bars + per-sample drill-down; CI-analyzer auto-reverts (~70% precision). Red Hat: Wasserstein distance over response distribution avoids flat-threshold false positives.
- **TRT-LLM (B):** trtllm-eval shares the CI accuracy suite; KEY lesson: they had to STABILIZE scoring variance before thresholds meant anything (our 56-62 mimic scores have exactly this problem).
- **MLPerf (B+):** the perturbation test — a deliberately degraded arm MUST FAIL the gate (positive control proving sensitivity).
**GATE DESIGN "MIMIC-D" (<=15 min):** freeze >=300 stratified prompts through the release engine (raw logprobs, fixed seed) storing greedy-hash + top-20 logprobs at checkpoints + adherence; per-arm replay computes same-top-p, mean/max dlogprob, KL-top20, dp percentiles, divergence index; FAIL if same-top-p < 97.5% or mean dlogprob > 10x noise floor or NEGATIVELY-TAILED dp percentiles (the llama.cpp tail test) or adherence < baseline − 3 pts (PAIRED, not N, gives power — 70 unpaired MCQs cannot see 2-4pt drift). Pooled confirmation = both arms through the same replay (catches interactions).
