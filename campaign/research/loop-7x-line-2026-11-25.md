# The 7x repeated line: three-lane verdict on the stacked control vectors (2026-11-25, 19:00-19:12)

Operator report, ~19:00: during live testing, the model emitted the same line seven times consecutively
("- In `loadRound`, if chambered and slide in battery and mag length? OK." x7). Operator hypothesis: "the 2
vectors stacked". Three read-only investigators (engine mechanics, written record, live log); no boot, no edit,
no request sent; the standing server stayed up throughout.

## Verdict

**The stack does not double-apply, and the loop's phase points away from the persona vector — but the stack as a
whole has never been A/B'd against loops, and the standing had nothing armed that could see a repeated LINE.**

1. **Mechanics (`cvec.cu`, `layer.cpp`, `prefill.cpp`):** persona = add at layer 8 only, scale 0.3, phase-gated
   (off during thinking, armed at the first `</think>`); refusal = project over layers 1-47 at scale 1.0 (full
   removal per layer, the F-376 range), always on. At layer 8 both fire sequentially on one stream — the project
   acts after the add and strips only its component along the refusal axes, and the persona row is
   Gram-Schmidt-orthogonalized against those axes to cos <= 0.0053 (`tools/persona_vector.py:329-347`): the
   interaction term is ~zero. No path applies a vector twice per layer (the prefill fused kernel fuses only when
   exactly one table acts, `prefill.cpp:4777-4785`).
2. **Phase evidence:** the loop-shaped request of this boot (R3: 22,165-token prompt, 67,761 generated at
   321.9 t/s = +49 % over neighbours, drafts 99.06 % accepted, suffix drafts 99.03 %, client-cancelled) never
   left the thinking phase per the server's own progress beats. With `--cvec-phase-table 1` the persona gate is
   CLOSED there: the constant steering during that loop was the refusal ablation plus temp-1.0/top_p-0.95/top_k-20
   sampling with no penalty. If the operator's pasted line came instead from the 75.8k-token answer request (R2),
   both vectors were active — the logs carry no text, so this is unsettled; gate instrumentation would settle it.
3. **Why it ran so long (all confirmed in the live path):** repetition/frequency penalty 1.0/0 everywhere and
   presence 1.5 only on the instruct card (`server.py:8744-8747`; the config has no `sampling` block); the #606
   guard counts single TOKENS (256) and cannot see a repeated multi-token line (`server.py:271-282` says so); the
   #728 passage-loop detector is off by default and absent from the standing config — and even armed, 7 repeats
   of a ~13-word line is ~4.5 % of its 2,000-word window against a 25 % threshold. Probabilistic drafting is
   distribution-preserving (cannot start a loop) but makes one CHEAP: R3 accepted 99 % of drafts and decoded
   half again faster; `STRATA_TYPICAL_ACCEPT=0.2`'s rescue re-inserts tokens the target distribution rejected
   (`generate.cpp:17107-17113`, active this boot on every long request).
4. **What the record adds:** dose degeneration is a banked failure mode of this vector class (r01's output-head
   build collapsed at 0.10; r02 damaged facts at >= 0.35) — but never at the armed r03 dose (0.3 on one layer,
   ~1.2 read-out dose under the 4x hyper-connection sum, half the measured 0.6 knee). F-17 banked
   phase-gated steering as disturbing ("mid-generation distribution discontinuity at the arm point"); the
   per-table re-adoption of 11-24 validated 70 MMLU questions and register, never long free-form reasoning.
   Banked asymmetry: on a conversation-cache miss, prior-turn ANSWER tokens are re-prefilled with the gate
   closed though they were generated with it open (12-phase VERDICT :66-68) — a history mismatch in exactly the
   long multi-turn chats where loops appeared.

## Proposed order (cheapest falsifier first; nothing executed yet, awaiting the operator)

1. **Instrument the blind spots** (zero behavior change): one line at the phase-gate flips
   (`generate.cpp:17196-17205`) and per-request logging of the client's sampling keys (the engine logs none
   today). Two small diffs.
2. **The settling A/B, no reboot:** replay the looped conversation twice with identical client sampling, once
   with the per-request `cvec=0` switch (`server.py:1635-1638`): loop recurrence, draft acceptance, rate. If it
   loops with `cvec=0`, the vectors are exonerated and the cause is sampling posture.
3. **Arm `reasoning_loop_recovery`** (one config key): the in-tree medicine for whole-passage loops, priced in
   the overview paper's queue alongside the greedy-card defect (`sampler.cu:1259-1269`: temp-0 argmaxes over
   penalized logits; queued, unstarted).
4. **If vectors are implicated:** dose-ladder table 1 (0.3 -> 0.15) and unscoped-vs-scoped on LONG reasoning
   runs — the regime F-17's negative lived in and the 11-24 validation never measured. If exonerated: a
