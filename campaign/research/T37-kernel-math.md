## 3. IMPLEMENTER-READY CANDIDATES (VALUE-RANKED)

### 3.1 — TC-hc mma rungs (the hc line, window's largest soft line) — band **+6..12% M1** [HYPOTHESIS from banked line values]

**Mechanism.** Move the hc read's down/up dots off the unpack+FMA CUDA-core path (hard cap: 128 elem-MAC/clk/SM, and per §1.3 the real binder is ~205 KB outstanding bytes vs the 1.36 MB saturation requirement, plus the 40-add accumulator chain) onto `mma.sync.aligned.m16n8k16.row.col.f32.bf16.bf16.f32` with weight-side cp.async pipelines. The multiply work itself is trivial (629 MFLOP/window → 2.6 µs at 238 TFLOPS — 0.2% of the line); the mma form wins by *restructuring the memory pipeline*: weights staged via cp.async 16 B into swizzled smem, consumed by `ldmatrix.x4` (FA-5090's v4/v5 lesson: x4 halves ldmatrix count; prefetch-under-MMA overlaps the tail), no per-element FMA chain at all.

**Cost anatomy (the F-232 read).** Down GEMM per (layer, read): `[T × 10240] × [10240 × 320]` (+ 4 inject rows), weights 6.55 MB bf16, activations ≤ 8×10240 fp32 (40 KB, resident). Up GEMM: `[T × 320] × [320 × 10240]`, weights 6.55 MB, output `mixed` + QFUSE q8_1 tail (fused_gr.cu:219-249 semantics preserved). ### 3.3 — GDN prescale: refutation-with-attribution design (the honest disposition of T35 B4)

**What is now established (supersedes T35's framing):**
1. **No bit-preserving reformulation exists.** Exact-match acceptance is a discontinuous function of the verify logits; any floating-point reassociation of the recurrence's output dot eventually flips a borderline draft/target pair. The identity `o = g·(S·q) + (q·k)·δ` *is* the reassociation — the baseline order `o = q·(gS + kδ)` and the identity form cannot both hold bit-for-bit except at the (measure-zero) set of inputs where every intermediate rounds identically. So deliverable branch (a) "bit-preserving form" is **closed by proof, not by measurement**.
2. **The perf mechanism is mostly absent here.** MSInfer's decode win = redundant state reads + scalar-sync removal (paper §5.2, fetched) — our state is register-resident (`s[RPG]`, one read per window); the in-tree PS form (`verify_kernels.cu:296-345`) costs +1 mul/elem and buys one dependency-chain shortening (output-dot bulk before `delta`). Op count per element: baseline 4 (kv-FMA, update mul+FMA, out-FMA) vs PS 4 (x-mul, kv-FMA, out-FMA, update-FMA) — **no reduction; ILP shape only**.
3. **The canary move is quantitatively inconsistent with the identity.** PS adds one rounding per product in the kv and o dots: RMS rel ≈ u₃₂·√(2·32)/√3 ≈ **2.8e-7** [ESTIMATE, stated model] — the GDN_CHUNKED class (3e-7 prefill, M3b in-band, adopted). A 15-point acceptance drop (90→75-81) requires a logits perturbation orders of magnitude larger. Leading hypothesis: **composed-boot confound** (the T36 leg carried the lifecycle arms; no prescale artifact exists in campaign/results, §1.2.4). Alternative: a defect in the PS specialization (e.g., an interaction with the QFUSE q8_1 tail or the snapshot path) — the code read found no barrier or uninitialized-read hazard (need_out is block-uniform; `red_qk` consumed only under the same predicate), so the confound remains the lead.
4. **The value if it's clean is small.** rec = 0.23-0.28 ms/window (F-218: .28 light/.70 heavy); the chain-shortening's realistic take is 10-25% of the line → **+0.3..0.8% M1** [ESTIMATE] — five-boot pooled territory (the sub-4% law), and Kachua's B=1 lesson (direct-register vs smem staging) is the only other micro-rung on the same line (neutral prior here: our staging amortizes 512 threads/head).
**Cheapest isolated attribution (owed to the ledger regardless of disposition — one boot, ~1-2 h):** standing recipe + `STRATA_GDN_PRESCALE=1` ONLY: 3× M3b + acceptance A/B + one `STRATA_LOGPOS` pair scored by `tools/kl_yardstick.py` (expect mean KL ~1e-7..1e-6 if clean) + the boot console artifact saved to `campaign/results/` (fixing §1.2.4). Outcomes: (i) canary in-band → the F-276 STAY OFF dissolves into a normal small candidate (five-boot pooled, +0.3..0.8% band); (ii) canary moves on an ISOLATED boot → real defect: run `gdn_parity` vs the CPU reference at 1e-6 before touching anything else. **Rollback:** unset the env (default-off, in-tree). This is also the vehicle for the Kachua micro-rung: a `STRATA_GDN_DIRECT` register-load variant rides the same bench for free.
